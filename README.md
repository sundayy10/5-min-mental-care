# 5-min-mental-care
> 5분 안에 감정을 기록하고 정리하는 미니멀 멘탈케어 서비스

### 사용자들이 하루 5분 이내로 오늘의 감정을 쉽고 빠르게 기록하고, 자신의 감정을 객관적으로 이해하고 마음을 정리할 수 있도록 돕는 미니멀한 모바일 멘탈케어 서비스.
### 시간대에 맞추어 자신이 느낀 감정을 기록하고, 하루 전체를 되돌아보고 하루의 감정을 입력해야 함

---

## 사용 방법

1. 로그인 (카카오 / 구글)
2. 감정 선택 (이모지 클릭)
3. 간단한 메모 작성 (최대 150자)
4. 저장 버튼 클릭
5. 하루 감정 요약 선택
6. 통계 및 그래프 확인

---

## 사용 예시 ★ 실제 출력/화면

| 화면 | 설명 |
|------|------|
| 로그인 페이지 | 브랜드 소개 캐러셀 + 카카오/Google 로그인 버튼 |
| 대시보드 | 오늘의 감정 완성도 프로그레스 바 + 세션 타임라인 |
| 감정 기록 시트 | 감정 카드 그리드 → 상황 태그 → 한 줄 메모 → 저장 |
| 마음 분석서 | 7일 추이 꺾은선 차트 + 도넛 분포 차트 + AI 인사이트 |
| 설정 페이지 | 세션 템플릿 프리셋 (4구간 / 매시간 / 3구간) + 직접 편집 |

## 입력 / 출력

| 구분 | 내용 |
|------|------|
| 입력 | 감정 카드 선택 (긍정 / 안정 / 부정), 상황 태그 (최대 3개), 한 줄 메모 (최대 60자) |
| 출력 | 세션별 감정 기록 저장, 완성도 프로그레스 업데이트, 통계 차트 반영 |
| 설정 입력 | 세션 이름 / 시작·종료 시간 직접 입력 또는 프리셋 선택 |
| 저장 방식 | 현재 버전은 인메모리 상태 관리 (새로고침 시 초기화) |
